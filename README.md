# 隧道收敛测缝台

测量员登记里程桩号与收敛毫米值。接口进程内后台线程认领待判行（不另起 worker 容器），按绝对值是否不超过 3.0 mm 给出合格或超限。页面是 Svelte。

交班走**冻结简报**：测量员在「交班签出」专页按下生成，服务端把那一刻的合格 / 超限 / 待判计数与最近 5 笔提要渲染成正文写库；此后在线数据再怎么变，已生成简报的正文一个字都不改。二衬交班共用同一份简报，没有旁路。


## 技术栈

- 后端：Flask、Gunicorn、SQLAlchemy、进程内认领线程
- 前端：Svelte、Vite、nginx 反代 `/api`
- 数据库：PostgreSQL 16

## 交班签出（冻结简报）

页眉进入「交班签出」专页，三块：

1. **生成按钮**：只有测量员可见可点。按下后服务端在同一事务快照内统计合格 / 超限 / 待判笔数、取最近 5 笔，渲染为正文并整体写入 `shift_briefings` 表。计数不接受任何前端传参，无法手改预览充数。
2. **历史清单**：历份简报按时间倒序排列，测量员、巡检员都可看。
3. **正文预览**：只读渲染库里那份冻结正文，附合格 / 超限 / 待判 / 总计计数标签。

冻结语义：

- 生成后再提交新单、待判单被认领线程判完，旧简报数字与正文都停在生成那一刻，不随在线数据变。
- 一张单都没有时也能生成，计数为 0，正文注明空班。
- 巡检员没有生成入口；直接打 `POST /api/briefings` 也返回 403。
- 简报只可新建、读取，没有 PUT / PATCH / DELETE 旁路。

接口：

| 方法 | 路径 | 权限 |
|------|------|------|
| POST | `/api/briefings` | 测量员，按当时统计生成并落库 |
| GET | `/api/briefings` | 登录可读 |
| GET | `/api/briefings/<id>` | 登录可读 |
